Phase 4: architecture not started

Collapse command boilerplate

BaseCommand.execute becomes a template method. Each command declares buildCommand, metricName, errorMetricName, buildTags, parseOutput. Command files shrink by about half; the {metricName, metrics, tags} contract stays.

Probe targets as configuration

Move the batches out of index.js to Service/config/probes.js, driven by PING_TARGETS / CURL_TARGETS. Add them to .env.template and the compose environment: list. No rebuild across the Pis.

In-process scheduler replaces cron

Minute-aligned scheduler in Node; keep the one-shot CLI mode. Deletes containerScripts/, the env dump, cron in the Dockerfile, and the log bind mount. Also lets frequent skip the minute of the node's own speed test.

After Phase 4: diff measurement and field names. They must be byte-identical, or the dashboards go blank.
